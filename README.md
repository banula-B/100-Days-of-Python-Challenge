## 📖 About This Challenge

This repository contains my **100 Days of Python Challenge**, a structured learning journey designed to take me from Python fundamentals to intermediate and advanced Python programming through consistent daily practice.

The challenge focuses on **learning by building**.

Instead of only studying Python syntax and theory, each learning day includes:

* 📚 New Python concepts
* 💻 Coding practice
* 📝 Exercises
* 🚀 A practical project
* 🔍 Problem-solving
* 📖 Notes and documentation
* 🌱 Git and GitHub practice

The goal is not simply to finish 100 days, but to build a strong Python foundation that can be used for **software development, automation, data science, artificial intelligence, machine learning, and future projects**.

# 📝 Daily Learning Structure

Each day follows a consistent workflow.

### 1. 📚 Learn

Study the day's Python concepts.

### 2. 💻 Practice

Write small programs using the concepts learned.

### 3. 🏋️ Exercises

Solve several problems without immediately looking at solutions.

### 4. 🚀 Build

Create the day's mini project.

### 5. 🔍 Review

Review the code and identify areas that can be improved.

### 6. 📖 Document

Update the corresponding Markdown notes.

### 7. 🌱 Commit

Commit the day's progress to GitHub.

# 🔐 Security & Best Practices

When projects begin working with APIs, passwords, databases, or other sensitive information, sensitive values should **never be committed directly to GitHub**.

For example:

```text
❌ API_KEY = "my-secret-key"
```

Instead, environment variables and `.env` files will be used where appropriate.

The `.gitignore` file should prevent sensitive or unnecessary files from being committed.
